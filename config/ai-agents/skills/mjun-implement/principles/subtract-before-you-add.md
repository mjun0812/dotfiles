# 足す前に引く (Subtract Before You Add)

構造を変える前や機能を足す前に、使われていないコード、重複した検証、中身の無い参照を消す。単純になった状態の上に足す。

不要なものの上に足すと、残すべきものと消すべきものの区別がつかなくなり、後から読む人やagentは、消し忘れたものを見本として真似る。

## 基準

- 呼ばれていない関数、到達しない分岐、使われない引数と設定を先に消す
- 境界で確かめ済みの値を、内部で確かめ直さない ([境界に検証を集める](boundary-discipline.md))
- 想定しただけの例外ケースに備えたguardやparserを書かない。求められている範囲だけを扱う

## 当てはめないとき

消したいものが担当taskのBoundaryの外にあるとき。消さずに、構造化ブロックで報告する (implementerは `CONCERNS`、reviewerは `NOTES`、refactorerは `NOTES_SKIPPED`)。

## 飛ばした合図

新しいコードが、古いコードと同じことをする別の処理として並んでいる。
