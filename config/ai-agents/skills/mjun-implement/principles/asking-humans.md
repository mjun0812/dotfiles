# 人間に聞くもの・聞かないもの

人間の時間は、人間にしか決められないことだけに使う。調べれば分かることを聞くと人間の手を止め、人間が決めるべきことをAgentが決めると、選ばれていない振る舞いや範囲が紛れ込む。

## 聞かないもの

- コード、規約、ドキュメント、steering、ADR、一次資料を調べれば分かる事実
- 動かせば分かること (挙動、タイミング、見た目の差)。試作や小さな実験で確かめてから、結果を見せる。どれを選ぶかが好みで決まる比較だけを、観察結果を添えて聞く
- 元に戻せる作業の進め方 (taskの切り方、内部の設計、テストの作り方)

## 聞くもの

- 価値判断、スコープ、利用者から見える振る舞い、公開interface、根拠から決まらないtrade-off
- 取り返しのつかない操作と、外への送信 (merge、push、削除、Issueの起票)
- repositoryの持ち主や公開範囲で決まること (ADRや用語集をcommitしてよいか)

specの論点の詳しい分類は、mjun-specifyの `references/decision-authority.md` にある。

## 聞き方

- 選択肢、推奨、その理由を添える。選択を促すtool (AskUserQuestionなど) を使い、使えなければテキストで選択肢を示す
- 互いに依存しない質問は1回にまとめる。前提が決まっていない質問は、前提の答えを得てから聞く
- 長い自律実行を始める前に、途中で要る確認をまとめて聞く。途中で新しく出た確認は、止まって待たずに結果の報告で聞く。人間が席を外している間に止まると、その時間が無駄になる
