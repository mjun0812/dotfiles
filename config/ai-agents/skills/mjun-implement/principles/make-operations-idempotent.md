# 何度実行しても同じ結果にする (Make Operations Idempotent)

状態を変える操作は、何回実行しても、前回の実行が途中で落ちていても、同じ正しい状態に収束させる。

コマンド、ライフサイクルの操作、処理のループでは、落ちる、再起動する、やり直すのが普通である。前回の残り物で結果が変わると、再実行のたびに原因を調べ直す必要が出る。

## 基準

- 前回の実行が何をしようとしたかではなく、今ある状態から各段階を導く。今の状態と目標を比べ、差分だけを当てる
- 実行が残すもの (lock、一時ファイル、書きかけの記録、確保したjob) は、次の実行が古いと判断できる形にする。一時パスに書いてからrenameする、作った順ではなく内容で比べる、などである
- 3つの問いで確かめる。2回続けて実行したら、どうなるか。前回があらゆる箇所で落ちていたら、どうなるか。再実行で同じ最終状態に収束するか

## 当てはめないとき

1回しか実行されないことが、構造で保証されている操作。

## 飛ばした合図

再実行の前に、手で何かを消す必要がある。
