# 評価基準の変更記録

criteria.md が現在の基準の唯一の正本であり、このファイルは基準がどう変わったか (差分・理由・旧基準の痕跡) だけを記録する。判定にはcriteria.mdだけを使い、このファイルは旧基準の痕跡の検出と根拠の表示にだけ使う。

追記専用で、既存entryの本文は書き換えない。書き換えてよいのは `Status` だけ。同じ観点についての新しいentry (上にあるもの) が古いentryを上書きする。

## entryの形式

- 見出し: `## YYYY-MM-DD <観点>: <要約>`
- 種別: `強化` (要改善シグナルが増えた。痕跡は要改善)、`廃止` (要求が消えた。痕跡は削除任意で減点しない)、`緩和` (禁止が解けた。痕跡は指摘しない)、`手順` (評価手順・出力・表記の変更で判定は変わらない)、`初版`
- 変更: 旧 → 新
- 理由: なぜ変えたか
- 痕跡: 旧基準に合わせて書かれた箇所を見つけるパターン。無ければ「なし」
- 修正: 痕跡の直し方
- 由来: commitとPR
- Status: `active` (痕跡が残りうる) / `retired` (新しいentryで上書きされた、痕跡の掃除が完了した、または痕跡が定義上存在しない)
